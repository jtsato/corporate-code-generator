# Roadmap

This is the canonical roadmap for Corporate Code Generator. It is organized by Release -> Phase -> Milestone and records only known status, outcome, and evidence. Current measured counts and detailed generated file inventories belong in [Current State](docs/project/CURRENT-STATE.md).

Allowed milestone statuses are: Done, In progress, Planned, Deferred, Superseded, and Historical information unavailable.

## Future optional work

Future work remains outside the current release unless explicitly approved: optimistic locking, ETag/If-Match, authentication and authorization, additional databases, deployment scaffolding, remote registries, and plugin systems. NestJS as a second stack is no longer future-optional work; it is tracked under Release 2, Phase 7. After the locally verified package-backed i18n and in-memory uniqueness implementation, the remaining NestJS parity gap is: a real database and ORM; soft delete and restore; auditing; CORS and environment configuration profiles; generated repository hygiene (`.gitignore` and `README.md`); container packaging; generated continuous integration; advanced locale negotiation beyond the generated English/Portuguese catalogs; and an architecture-boundary lint. That gap, together with a NestJS multi-module variant, is no longer undifferentiated future-optional work: it is sequenced as Planned milestones 7.20 through 7.29 above, with its gap inventory, its ten structural decisions, and the departures it requires from the in-memory-only reference project recorded in the [NestJS Parity Gap Plan](docs/project/NESTJS-PARITY-GAP-PLAN.md). Each of those milestones remains unscheduled until its structural decisions are approved and its own ADR is written.
