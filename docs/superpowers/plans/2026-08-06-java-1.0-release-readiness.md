# Golden Path Java 1.0 Release Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to execute this plan task-by-task with review checkpoints. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close Milestone 6.30 by proving the Java multi-module Golden Path remains release-ready after Milestone 6.29 and by aligning measured project documentation with the committed baseline.

**Architecture:** This is a release-readiness audit, not a new generation capability. The deterministic generator and generated Java contracts remain unchanged unless validation exposes a concrete regression; documentation records measured facts in `CURRENT-STATE.md`, release status in `ROADMAP.md`, and quality policy in `QUALITY-GATES.md`.

**Tech Stack:** TypeScript generator, npm/Vitest, generated Java 25/Spring Boot, Maven reactor, Markdown project documentation.

## Global Constraints

- Do not add a new runtime capability in Milestone 6.30.
- Preserve the Clean Architecture boundaries and deterministic generation invariants in `AGENTS.md`.
- Do not install dependencies, commit, push, merge, rebase, or create a pull request.
- Change only documentation or validation metadata justified by measured evidence.
- Treat `docs/project/CURRENT-STATE.md` as the source of measured counts, versions, scripts, smokes, CI, and validation results.
